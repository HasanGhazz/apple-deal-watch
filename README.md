# Apple Deal Watch

A single-file, mobile-first web app for tracking Apple product deals. Everything lives in `index.html` (HTML, CSS and JS inline, Inter loaded from Google Fonts), with light and dark themes.

## Run it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
